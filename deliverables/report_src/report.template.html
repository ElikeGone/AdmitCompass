2Motivation and target user

Who has the problem. International professionals who are considering a U.S. MBA to change careers, for example an auditor who wants to move into management consulting. They have to decide which programs to research, which test to take and what to do this week, usually with no admissions consultant and little knowledge of how U.S. applications work.

How they handle it today, and what that costs

  • Rankings first. Rankings measure prestige, not whether a program leads to this person's target role in this city.
  • Costs are scattered and inconsistent. For MIT Sloan, the official page gives tuition and fees of $91,892 (2026–27), Poets&Quants estimates a one-year cost of $144,325, and Clear Admit compiles $138,310 (2025–26). Third-party for the last two. They measure different things, and the official site publishes no total.
  • Visa questions are high-stakes. STEM designation affects OPT eligibility, but it is not a sponsorship promise. Employer sponsorship history sits in U.S. Department of Labor disclosure files: 596,552 FY2025 cases across four quarterly spreadsheets (~420 MB).
  • Research doesn't become a plan. Knowing facts doesn't tell an applicant what to do in a 10-hour week.

Supporting features (verified to work)

  • Ask AI: a bounded copilot (one model call per question, plus at most one repair) that answers from the evidence store with citations. Checked live with 3 real questions Measured (§5).
  • Voice input in the Ask AI box through the browser's Web Speech API. Speech appears in the box and is not sent automatically. The project owner tested it manually in Chrome with a physical microphone. In browsers where the speech service is blocked (for example Brave, or the Electron preview pane), it shows "Microphone unavailable".
  • Accounts (on by default) for saved programs, the profile and weekly-task progress. Passwords are hashed with scrypt, and sessions use an HttpOnly cookie. Guests can use everything else.

4The agents

A code orchestrator (no model) runs four gpt-6-luna agents in a fixed order. Each agent gets a typed input, may call only its own read-only tools, and must return JSON that passes a Pydantic schema. After every agent, deterministic grounding checks run before anything is handed on (backend/app/orchestrator.py, AGENT_SPECS).

Why gpt-6-luna, at low reasoning effort: it's the only model the course key permits. Low effort kept each agent call to a few seconds; in the saved run, reasoning tokens were 696 of 8,779 output tokens. Why four agents and not one: each step has a narrower prompt and toolset, so failures can be traced and checked per step (the trace records every call). The Skeptic reviews work it didn't write. The cost is latency and tokens: four sequential agents took 53.8 s and 9 requests in the saved run, against 4.4–8.5 s for an Ask AI answer (§5).

One real run, step by step Measured Fictional demo

Run 20261024T032006Z_fixture-audit-consulting-ghana, 2026-10-24, live gpt-6-luna, Portkey cache force-refreshed. Source: trace.json (42 events) and report.json. This saved run is the app's default "Sample Analysis".

  1. Orchestrator validates the profile (PII and injection screens) and starts a budget of 25 requests and 200,000 tokens.
  2. Pathway Matcher (3 requests): it called search_programs (max cost $140,000, state MA), then get_program_overview for 5 programs, and answered (6,166 input tokens on the last call). Schema and grounding passed. Shortlist: MIT Sloan (strong fit), Yale SOM and Duke Fuqua (moderate). The model excluded Chicago Booth and Tuck as less aligned with Boston; no code rule removed them.
  3. Evidence Analyst (3 requests, 8 tool calls): 3× get_program_facts, 2× compare_employment_metrics, 3× get_sponsorship_evidence for management consulting in Boston. Grounding: 0 violations. Results: MIT affordability unknown (no official cost of attendance), Yale within budget ($128,976), Duke within budget ($118,974).
  4. Strategy Planner (2 requests): it fetched the test policies and wrote the plan: "take timed GMAT and GRE diagnostics, then choose". Validation downgraded 1 evidence-less "verified" claim to an inference. Grounding flagged 1 sentence for "guarantee" wording (a false positive on a correct warning; the rule was fixed afterwards, §6).
  5. Skeptic (1 request): 2 findings. Medium: Duke's budget fit omits that the cost source doesn't state single-student scope. Low: MIT's "strong" fit rests on location alone. It requested no revision, so both findings are shown to the user.
  6. End: completed_with_violations (the 1 flag), 9 / 25 requests, 63,535 / 200,000 tokens, 17 tool calls, 53.8 s.

How the Skeptic improves reliability. In this run its findings narrowed two claims that grounding couldn't catch, because both were true but overstated. In two other Ghana runs it requested a Pathway Matcher revision, which re-runs that agent and everything after it; both of those runs then hit the old 20-request cap (docs/run_variability.md). The Skeptic catches judgment problems; the grounding code catches factual ones.

Two different AI paths

Four-agent analysis (above): about 1–2 minutes, capped at 25 requests / 200,000 tokens / 40 tool calls / 300 s per run. Ask AI copilot: no agents and no tools. Deterministic keyword retrieval picks at most 40 facts, then one model call answers, and grounding checks it. If it fails, one repair call follows; if that fails too, a deterministic list of the sourced facts is shown instead of unverified text (backend/app/copilot/, docs/copilot.md).

6Safety and responsible AI

The model is treated as untrusted. Defenses are deterministic code around it: input screens, typed schemas, grounding checks against the evidence store, budget caps and fixed refusals. AdmitCompass does not guarantee factual correctness and has not been security-audited for production.

RiskDefense implemented (file)
Hallucinated or unsupported factsClaims must cite evidence ids that exist for that program. Numbers in verified claims must appear in the cited evidence or the applicant's profile. STEM and sponsorship statuses are recomputed from the store (agents/grounding.py).
Provenance and unknownsEach fact has a status (verified / source-backed paraphrase / estimated / unknown), a source URL, a date checked and a data period. Data older than 18 months is flagged as stale. Missing facts stay unknown and are never filled in.
Prompt injectionPattern screens on every profile string, source excerpt and employer name. Tool results are wrapped as {note: untrusted, data}. Output can't create facts, because grounding overwrites it.
Personal data (PII)The profile schema forbids extra fields; emails, phone numbers and passport numbers in free text are rejected. Citizenship is a country only. The trace stores metadata only, never prompts. Run records mask profile-derived tool arguments.
Immigration and sponsorshipPersonal visa-eligibility questions are refused in code with a referral to a DSO or attorney. "Will sponsor" and guarantee wording is blocked. Employer data is labeled "historical H-1B filings, not a guarantee of sponsorship". STEM is never presented as an immigration benefit.
Admission and scholarship oddsOdds questions are refused before any model call. Odds wording in model output is removed. The product shows no match scores.
OverspendingPer-run caps: 25 requests, 200k tokens, 40 tool calls, 300 s. Each server allows 3 live analyses, with one run at a time and explicit confirmation. Ask AI: 6 questions per minute and 40 per hour per client, 200 per server per day.
Accounts and sessionsscrypt password hashing, an HttpOnly session cookie, same-origin checks on state-changing requests, and no keys sent to the browser. Public errors are sanitized (core/public_errors.py).
Voice privacyThe microphone is requested only after a click. The browser does the speech-to-text (in Chrome this may use the browser vendor's online service). AdmitCompass receives only the text, which is never auto-sent. Listening stops when the panel closes, the tab is hidden or the page changes.

Broader red-team suite and real failures

  • 26 / 26 scenarios pass Mock-tested, including injection through profile fields, API overrides and employer names; leaked keys in errors; malformed JSON; fabricated evidence ids; PII; repeated paid runs; HTML injection (safety_test_matrix.md). 6 vulnerabilities were found while building it and fixed.
  • Budget caps worked in live runs Measured: three real runs stopped cleanly at their request cap (14/14 and twice 20/20), saving a partial report.
  • A malfunction was found and documented: a stale rule overrode correct employer evidence in one U.S. run (malfunction_sponsorship_status.md). The run was kept unedited and the rule fixed.
  • A false positive was fixed: a correct "do not treat as a guarantee" warning had been flagged (false_positive_guarantee_negation.md).

Human oversight. The app gives decision support, not admissions, legal or immigration advice. It tells users to confirm with schools, the international student office (DSO) and qualified advisors before applying, paying deposits or making visa plans. Pattern screens can miss paraphrased attacks. The second line of defense is that model text can't create a fact the store doesn't hold, but no live adversarial test of the paid model was run Not verified.

What these three observations show

Real people used AdmitCompass, and each named a specific favorable aspect: ease of use (T1), voice input (T2), and the chance to explore options and learn the application process without prior experience (T3). That's an early signal that the interface was approachable for these users and that voice input and first-time-applicant guidance were noticed as valuable.

What they cannot establish

Whether AdmitCompass saves time, improves decisions or leads to correct understanding; how typical applicants would react; or how it compares with ChatGPT or manual research. No task completion, scores, timing, clarification questions, confusion moments, improvement suggestions or verbatim quotes were recorded, and neither was the profile used. It's a convenience sample, the feedback was recalled, and the facilitator may have influenced it: early qualitative evidence, not proof of effectiveness. A timed protocol and 8-point rubric are ready in experiments/user_testing/.

What the evidence supports today: the product reaches 30 programs and turns 596,552 raw DOL cases into employer-specific filing history. It stops the unsafe outputs it was tested against, and it produces a sourced plan in about one minute for a fictional profile. Not yet measured: time saved for a real applicant compared with manual research, or decision quality Not verified.

8Limits and next steps

What doesn't work yet, or isn't proven

  • Uneven evidence: 5 programs detailed, 23 partial. Still open: MIT's official total cost, Rice's 2026–27 deadlines, Duke's GMAT median. HBS and Columbia block automated fetches (Columbia's figures came from files the owner saved manually); U.S. News couldn't be accessed.
  • Estimates vs official costs: where no official total exists (MIT), a labeled Poets&Quants estimate is shown. Third-party tuition for public schools may be the in-state rate.
  • Sponsorship: no school publishes sponsorship outcomes. Employer filings are historical (FY2025, 3 occupations, 5 cities) and depend on a reviewed alias table; no HBS employer list could be retrieved.
  • Model limits: shortlists vary between runs for one profile; pattern checks can miss rephrasings; Ask AI's keyword retrieval can miss school nicknames.
  • Cost, latency, users: no verified price, so dollar costs are unknown; the cost-cut result is a mock replay; a full analysis takes about a minute. Three testers, qualitative only.
  • Deployment: local only; SQLite and in-memory rate limits (reset on restart). Voice depends on the browser's speech service.

Proposed next steps Not built

  1. Timed user test with 3–5 international applicants: time to this week's action, 8-point task score, an approved quote.
  2. ChatGPT side-by-side test on both fictional profiles (prompts and scoring template ready).
  3. Validate the repair-mode saving live in a few approved paid runs; add dollar costs once a gpt-6-luna price is published.
  4. Widen detailed evidence beyond 5 programs, with scheduled re-validation.
  5. Connect Ask AI to a user's own analysis (today it uses the saved sample) and cut the repair rate.
  6. Host it with a shared rate-limit store, HTTPS and a privacy review.

Bottom line

AdmitCompass is a working, career-first, evidence-gated MBA advisor with measured token use and tested safety defenses. Its impact on real applicants is promising but not yet measured.
